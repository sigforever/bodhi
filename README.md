# BODHI · 菩提

> **不立文字，借指见月。**  
> 一座以「思源宋体」筑底、零依赖、可长期沉淀的禅宗与佛学交互阅读与观照应用。

---

## 特性与设计哲学

- **典籍级思源宋体排版**：优先调用 Windows 本地「思源宋体（Source Han Serif SC）」；若本地未安装，自动通过国内直连镜像按需加载在线思源宋体，并提供单段字号、行距、栏宽实时调节。
- **三款低饱和宋韵主题**：**玄墨**（默认暖墨黑）、**宣纸**（温润古纸白）、**松烟青**（汝窑青灰釉韵）。
- **零依赖纯静态架构**：无 `node_modules`，所有阅读批注、收藏、静坐次数与觉照手记均保存在本机 `localStorage`，支持随时导出/导入标准 `.md` 文件，适配 Dropbox 多端同步。
- **七大静谧研习模块**：
  1. **藏经精读（默认主视图）**：收录全本《心经》（260 字）、《信心铭》（584 字）、《参同契》（220 字）及《金刚经》《六祖坛经》《永嘉证道歌》《楞严经》《维摩诘经》核心精编；支持**白文素读**、**传统竖排书卷**、**凡夫执见 / 般若照见双视角**与**随文批注**。
  2. **觉悟全景**：五重转进交互星图（可直达关联经典）、唯识「八识转四智」对照、以及《金刚经》「A → 即非A → 是名A」三段论拆解。
  3. **十牛图**：廓庵十牛图十阶圆相交互轨迹与极简墨韵几何图腾。
  4. **五家法脉**：达摩至六祖、一花五叶传灯法脉溯源与祖师宗风档案。
  5. **公案参究**：十则禅门经典公案，支持随机抽参、隐藏式渐进揭示（疑情 / 透脱眼）与心得直通手记。
  6. **觉照手记**：统一管理自由手记、经文批注与公案心得，支持实时检索与一键导出 `.md`。
  7. **观息静室**：呼吸引导圆相、话头轮换、全屏沉浸模式与 Web Audio 合成引磬起止轻鸣。

## Windows 使用方式

### 方式一：独立无框窗口启动（推荐）
直接双击根目录下的 **`启动菩提.vbs`**：
- 自动查找系统内置的 Microsoft Edge 或 Google Chrome，以独立应用窗口（无地址栏、独立任务栏窗口）打开，无黑色命令行闪屏。

### 方式二：安装为 Windows 本地应用（固定至开始菜单 / 任务栏）
在终端或命令行运行：
```bat
启动菩提.bat --server
```
Edge 打开后，点击右上角菜单「应用 → 将此站点安装为应用」，即可像原生桌面软件一样固定到 Windows 任务栏。

### 常用快捷键
- `Ctrl + K`（或 `Cmd + K`）：唤起全局检索，直达任意经文段落、公案、法脉与手记
- `1` – `7`：快速切换七大研习模块
- `←` / `→`：在十牛图视图中步进前后阶次
- `ESC`：关闭检索面板 / 排版面板 / 退出观息静室全屏

## 离线思源宋体建议
若希望在完全断网的 Windows 环境下获得最高锐度与零延迟字体呈现，可下载开源免费的 **思源宋体（Source Han Serif SC / Noto Serif CJK SC）** 安装到 Windows 字体库，应用会自动识别并切换为本地直读。

## 项目结构

```text
bodhi/
├── 启动菩提.vbs            # Windows 静默独立应用窗口启动器（推荐双击打开）
├── 启动菩提.bat            # Windows 批处理启动器（支持 --server 启动本地服务）
├── index.html             # 应用主入口
├── manifest.json          # PWA 应用清单
├── assets/
│   └── icon.svg           # 宋韵圆相与朱砂印矢量应用徽标
├── app/
│   ├── styles.css         # 宋韵极简 × 瑞士网格设计系统（玄墨 / 宣纸 / 松烟青）
│   ├── font-loader.js     # 思源宋体本地探测与国内/海外双源按需加载器
│   ├── app.js             # 零依赖应用交互、SVG 图谱与手记持久化引擎
│   └── data/
│       ├── library.js     # 八部核心佛学与禅宗经典库（原典 / 直译 / 深解 / 双观 / 观照）
│       └── atlas.js       # 觉悟全景、唯识转智、金刚三段论、十牛图、五家法脉与公案库
├── docs/                  # 独立 Markdown 深度导读文库（00-map.md ~ 05-practice.md）
└── journal/
    └── TEMPLATE.md        # 线下参究手记 Markdown 模板
```
