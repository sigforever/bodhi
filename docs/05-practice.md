# 05 · 日用即道与实修指南

> 「若人静坐一须臾，胜造恒沙七宝塔。」  
> 然而静坐只是磨刀，真正的道场在**打开门后的每一个当下**。

---

## 一、两条基础功课：止与观

佛教一切实修，不出**止（Śamatha，奢摩他）**与**观（Vipaśyanā，毗婆舍那）**二字：

| 维度 | 止（定 · 澄静） | 观（慧 · 明照） |
| :--- | :--- | :--- |
| **核心作用** | 让浑浊翻涌的心水沉淀下来 | 在澄澈的水中如实照见实相 |
| **操作方式** | 轻柔安住于单一所缘（如呼吸出入） | 觉察念头、感受、情绪的生住异灭与无自性 |
| **关键要领** | **不控制呼吸，不与杂念对抗**；发现走神，轻轻带回即可 | **不评判、不认同**；看到「愤怒正在生起」，而非「我很愤怒」 |
| **常见偏差** | 沉溺于昏沉、发呆（死水定） | 变成头脑里的心理分析（干慧） |

> 禅宗的「静坐」强调**止观双运、定慧等持**：心如明镜，既极静（止），又极清亮（观）。

---

## 二、日常静坐极简仪轨（每日 15–30 分钟）

1. **调身**：端坐（散盘、单盘或坐于椅前三分之一），脊柱自然直立而不僵硬，双肩下沉，下颌微收，双眼微闭或半睁垂帘看前下方一米处。
2. **调息**：最初三口深呼吸，吐气时将全身紧绷随之放下；之后彻底交还自然呼吸，只觉察鼻端或小腹的微细起伏。
3. **调心**（二选一）：
   - **默照法**：什么都不做，什么都不求，只是清醒地坐着。念头来如浮云过虚空，不迎不拒，安住于那份宽广的觉知。
   - **参话头**：在呼吸平稳后，轻轻提起一句疑情（如「此刻听见声音的是谁？」「念起之前是什么？」），不找逻辑答案，只是静静凝视这股追问本身。
4. **出定**：结束时不急于起身，先搓热双手轻敷双眼，缓缓活动肩颈，带着同一份清醒步入日常。

## 三、日用觉照：把修行融进生活

- **行住坐卧**：走路时感受脚底与地面的接触；喝茶时只管喝茶，不一边喝茶一边活在明天的焦虑里。
- **情绪来袭的三秒留白**：当愤怒、嫉妒、委屈或贪求生起时，尝试在「刺激」与「反应」之间切开一道缝隙——先觉察身体的紧绷处，默念一声：**「这是一个正在经过的因缘现象，不是我。」**
- **观「拣择心」**：留意自己一天中说「这应该……」「我不喜欢……」的频率。每一次强烈的抗拒，都是一面照见我执的镜子。

## 四、修证路上五个经典陷阱

| 陷阱 | 表现特征 | 对治之药 |
| :--- | :--- | :--- |
| **1. 狂禅（理悟当证悟）** | 满口「本来无一物」「一切皆空」，却一触即怒、贪欲炽盛 | 记住「理可顿悟，事须渐除」，以日常境界检验自己 |
| **2. 耽空滞寂** | 极度迷恋静坐时的宁静空白，厌烦人际与琐事 | 回到《心经》与十牛图第九、十图：真定不离动用 |
| **3. 压念成石** | 以为「无念」就是把脑子清空，拼命压制想法 | 六祖云「无念者，于念而无念」，不随念转即是无念 |
| **4. 灵性傲慢** | 觉得自己比旁人清醒高明，暗生优越感 | 这是披着佛法外衣的更隐蔽的「我执」（法执） |
| **5. 执着境界** | 静坐中偶尔出现光影、轻安、喜悦，此后拼命想复制那种体验 | 《金刚经》云「凡所有相，皆是虚妄」，好境坏境皆是过客 |
